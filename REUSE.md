# Reusing the workspace

1. Clone and run the browser version first.
2. Set project purpose, questions, round membership and stage labels in `desk/questions.json`.
3. Add your images in the app. They stay in ignored `desk/media/`.
4. Use notebook, focused chat or storyboard without creating a page per conversation.
5. Configure Codex separately only if AI drafting is needed; optional OnlyChat remains an incomplete adapter.
6. Set a deadline and review actual evidence. Reconfigure delivery paths and manager modules for your project.
7. Build Windows shell for independent window placement, read-only side context and desktop popups.
8. Before committing updates, run tests and `git status --short`; never force-add ignored runtime data.

`Ctrl + +` or `Ctrl + =` increases text size; `Ctrl + -` decreases it; `Ctrl + 0` resets. The selected theme and font size persist in the browser profile. A fresh profile starts with defaults.

Saving is local; no cloud sync or GitHub publication of answers happens automatically. System-improvement notes are currently browser-local and exportable; recording one is not an automatic code-change request.
