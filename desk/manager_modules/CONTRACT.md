# 제작 관리자 · 모듈 계약 v1

관리자(persona)는 제출 목표, 고정 마감, 실제 증거, 우선순위를 관리한다. 작업 모듈은 입력·출력·읽기/쓰기 범위를 분리한다.

구조 참조: 이 PC의 OnlyChat 정본 `src/morph/ARCHITECTURE.md`에 기술된 Body Mod v2의 독립 Organ, 해시 기반 변경, 분리된 UI/서비스 구조. 해당 파일은 읽기 전용으로 참조했다. 이 앱은 Python 로컬 어댑터이며 OnlyChat Hub에 등록되거나 외부 BodyMod API가 연결된 상태는 아니다.

## 실행 규칙

- 버전·모듈 ID·목표·입력 파일 목록은 `__init__.py`에서 선언한다.
- 시작: 필요한 입력의 내용과 SHA256을 고정해 Codex에 전달한다.
- 병렬 한도는 2개이며 후보 수정도 같은 한도에 포함한다.
- 문서 검사와 게임 의미 검사는 원본을 수정하지 않고 구조화된 응답만 `manager-runs/`에 저장한다.
- 게임 후보 수정은 이전 작업자의 명시적인 단일 파일 인계와 예상 해시가 일치할 때만 허용한다. 정본 게임은 쓰기 대상이 아니다.
- 결과 수신 시 입력 해시를 다시 검사한다. 바뀌었으면 최신 결과로 승인하지 않는다.
- 작업별 상태와 결과를 저장하고 서비스 재시작 시 진행 중이던 작업은 중단 상태로 보존한다.
- 중지·마감은 이 관리자가 시작한 작업만 취소한다. 다른 앱·사용자 세션을 종료하지 않는다.
- 실제 파일 점검은 30초마다, 진행 보고 기록은 10분마다 한다. 남은 10분은 검증, 5분은 최종 정리를 우선한다.
- 자체 파일 인계/CAS는 BigBrother 예약을 대신하지 않는다. 이 앱은 신설된 별도 작업 폴더에서 동작하며 정본/경합 경로 쓰기나 컴퓨터 전체 예약 권한을 주장하지 않는다.

## 완료 판정

답변 수·시간 경과·AI의 성공 문구는 완료 증거가 아니다. 문서 렌더 검사, 실제 게임 관찰, 영상 재생/내용, 실제 제출 기록을 각각 구분한다. 하나가 빠지면 과제 전체는 미완료다.
