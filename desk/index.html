화면과 사용 방식

연결과 작업 진단

상세 오류는 앱 폴더의 debug/desk-debug.jsonl에 기록됩니다. 이 화면에서 연결 성공이나 코드 적용을 임의로 완료 처리하지 않습니다.

시스템 개선 요청

불편한 동작 → 원하는 동작 → 확인 방법을 편하게 적어 주세요. 이 브라우저에 자동 저장됩니다.

앱 코드 변경은 현재 Codex 채팅에서 요청해 주세요. 여기에 기록하는 것만으로 AI 코드 수정이 시작되지는 않습니다.

백그라운드 작업

답변 전달 → 기획 초안 작성 → 새 질문 4~5개 준비. 패널을 닫거나 다른 페이지를 작성해도 계속됩니다. 앱 창을 닫아도 로컬 서버가 실행 중이면 계속됩니다.

이 작업은 기획 제안을 만듭니다. 게임 코드 변경·Claude Studio 실행·영상 제작·업로드의 완료를 뜻하지 않습니다.

작업 배분과 질문 원칙

현재 예상량이 남은 시간을 넘습니다. 제출·검수 시간은 남기고 선택 기능을 줄여야 합니다. 미완료 단계는 그대로 표시합니다.

작업 시간은 추정치입니다. 이 앱의 기획 AI와 실제 코드·영상 제작은 별도 실행 단계이며, 예약된 모든 작업이 자동 실행 중이라는 뜻은 아닙니다.

시간이 지나도 완료 표시는 자동으로 바뀌지 않습니다. 실제 결과 확인 후 다음 단계로 이동합니다.
